# NewsExplorer: Frontend

This Project serves as a frontend service for the NewsExplorer application. Its purpose is to allow a user to sign up or sign in and allow them to search up and save a newsarticle with a keyword.

## Technologies Used

This project utilizes the following technologies:

- React.js: a JavaScript library for building fast, interactive user interfaces using reusable components
- Vite: a fast build tool and development server for modern web projects
- JWT: a compact, secure way to transmit information between parties as a JSON object, used here for user authentication and authorization.
